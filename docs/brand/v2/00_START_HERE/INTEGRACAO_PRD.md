# Integração com o PRD v1.1

Este pacote contém uma cópia dos documentos Markdown do PRD v1.1 em `12_PRD_PROJECT_CONTEXT/`, para funcionar de maneira autossuficiente quando anexado ao Claude Code.

**Precedência:** PRD A–F governa funcionalidades, segurança e regras de negócio. O pacote Brand V2 governa identidade visual, UI/UX e design tokens, preservando a direção minimalista já aprovada.

O PDF e a prévia estática são de handoff visual e não substituem a implementação funcional. O Claude deve auditar o repositório e propor tarefas/PRs antes de alterar arquivos.
