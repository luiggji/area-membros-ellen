# CAIXA FORTE | Brand & UI Handoff Kit — V2.0
**Agência-style delivery • produto digital • 20/10/2026**

Este pacote concentra o material de identidade visual para implementação do **sistema próprio Caixa Forte**, independentemente no primeiro lançamento, com futura integração ao ecossistema Ellen Conrado.

## Ordem de uso pela equipe
1. Abrir `11_BRAND_BOOK/CAIXA_FORTE_BRAND_BOOK.pdf` e ver `10_REFERENCES/approved_minimalist_dashboard.png`.
2. Consultar `05_UI_DESIGN_SYSTEM/STYLE_GUIDE.md` e `06_SCREEN_BLUEPRINTS/SCREEN_INVENTORY.md`.
3. Reutilizar `01_BRAND_MASTERS/` (logotipos transparentes) e `03_FAVICONS_APP_ICONS/`.
4. Integrar tokens de `04_DESIGN_TOKENS/` após auditoria da stack existente.
5. Abrir `07_IMPLEMENTATION_NEXTJS/demo/index.html` e os screenshots correspondentes para uma prova estática de UI.
6. Entregar `08_CLAUDE_CODE_HANDOFF/CLAUDE_HANDOFF.md` ao Claude Code e seguir gates QA/Git Flow.

## Status de aprovação
- **Aprovado pela usuária:** aspecto minimalista, suave, premium, com muito espaço em branco, pouca informação por tela; o nome Caixa Forte foi utilizado como nome de trabalho no projeto.
- **Ativos de trabalho existentes:** marcas em PNG geradas nesta conversa e reutilizadas fielmente, sem redesenhar a versão 3D.
- **Proposto para homologação:** cores HEX exatas, tipografias, SVG simplificado e parâmetros técnicos visuais; aprovação estética não equivale a registro de marca nem a arquivo original vetorial de agência.

## Regras não negociáveis
- Preservar o escopo funcional do PRD v1.1 e não reinstaurar a UI carregada dos mocks antigos.
- Nunca preencher telas de produção com membros, percentuais, depoimentos, compras ou eventos fictícios.
- Não colocar dados sensíveis de clientes em demonstrações.
- Não usar retratos gerados por IA como fotografia verdadeira de Ellen.
- Não embutir a Caixa Forte dentro do site Ellen Conrado antes da fase de integração planejada.

## O que o pacote não é
Não é repositório executável completo de backend, arquivo Figma nativo, marca registrada, fonte licenciada ou vetorização idêntica da arte raster 3D. É um handoff documentado para desenvolvimento, com protótipos de UI e recursos reais.
