# @caixa-forte/ui

Design system v1.1 minimalista (sidebar vinho, canvas creme). Fonte de verdade: `docs/G_DESIGN_SYSTEM_MINIMALISTA.md`.

- `theme.css` — tokens Tailwind 4 (`@theme`): `bg-cf-bg`, `text-cf-text`, `bg-cf-primary`, `font-editorial`...
- `cn()` — utilitário de classes.

Uso no app: `@import "tailwindcss"; @import "@caixa-forte/ui/theme.css";` + `@source` apontando para `packages/ui/src`.
