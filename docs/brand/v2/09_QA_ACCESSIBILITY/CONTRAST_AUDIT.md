# WCAG contrast rules

Use token pairings verified by the accompanying `contrast-report.json`.

Target minimum ratios for normal text: 4.5:1; for large text 3:1; essential nontext UI components 3:1. Test actual rendered UI with overlays, disabled states, photos and focus rings. Do not assume AI brandboard color labels correspond to exact values.

**Recommended combinations:** `ink` on `cream`, `plum950` on `white`, `white` on `wine700`, `white` on `plum950`, and dark text on blush/sand. Avoid `champagne` small text on cream/white. Color cannot be the sole signal of status.
