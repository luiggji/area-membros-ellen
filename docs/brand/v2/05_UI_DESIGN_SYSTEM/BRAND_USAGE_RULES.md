# Manual de aplicação de marca

**Primário:** `01_BRAND_MASTERS/logo-horizontal.png` para landing page, e-mails e peças largas. **Secundário:** `logo-stacked.png` para aberturas e social vertical. **Marca curta:** `symbol-3d.png` para avatar, sidebar recolhida e telas com pouco espaço (em UI muito pequena preferir ícone de app já exportado).

Não distorcer, aplicar filtros de cor sobre a marca master, separar as letras do ícone, colocar fundos muito ruidosos, sombreamento adicional intenso ou usar imagens com bordas recortadas incorretamente.

**Área de proteção:** >= 0,25x da altura do símbolo em volta do lockup; >= 0,18x para ícone sozinho. **Mínimos recomendados:** horizontal 180px em digital; ícone 32px apenas na versão favicon testada. Confirmação visual deve ser feita em dispositivos reais.

**Fundos:** logo plum PNG sobre cream/white; em fundo escuro use versão de símbolo independente ou obtenha variante de wordmark com lettering claro de um designer (não usar raster escuro que perca contraste). Prévia `horizontal-on-cream.png` é apenas mock de uso; não altera o master.

**Nota legal:** “oficial” aqui significa arquivo central de trabalho no projeto; não há validação de registro de marca nem master SVG original evidenciado. Mudanças exigem registro de decisão.
