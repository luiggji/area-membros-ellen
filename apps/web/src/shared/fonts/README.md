# Fontes

Arquivos variáveis (subconjunto latin, cobre português) copiados de `@fontsource-variable/*` 5.3.0. Ambas sob **SIL Open Font License 1.1**, que permite redistribuir junto com o software desde que a licença acompanhe. Os textos estão em `OFL-*.txt`.

| Arquivo                                    | Família          | Pesos   | Uso                                        |
| ------------------------------------------ | ---------------- | ------- | ------------------------------------------ |
| `playfair-display-latin-wght.woff2`        | Playfair Display | 400–900 | títulos editoriais (hero, curso, campanha) |
| `playfair-display-latin-wght-italic.woff2` | Playfair Display | 400–900 | frases editoriais em itálico               |
| `inter-latin-wght.woff2`                   | Inter            | 100–900 | interface, corpo, tabelas e números        |

Escolha do Brand System V2 (D-014, `docs/brand/v2/04_DESIGN_TOKENS/README_TOKENS.md`). Para trocar: substituir os arquivos, atualizar `src/app/layout.tsx` e registrar no `docs/D_DECISION_LOG.md`.
